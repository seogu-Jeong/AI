# 음성 텍스트 변환 프로그램 사용법

인터넷 없이, AI API 없이 내 컴퓨터에서만 동작하는 음성 → 텍스트 변환 도구입니다.

---

## 시작 전 준비

### 터미널 여는 법
1. 키보드에서 `Command(⌘) + Space` 누르기
2. "터미널" 입력 후 Enter

### 프로그램 폴더로 이동하기
터미널에서 아래 명령어를 입력하고 Enter 누르세요:
```
cd ~/transcribe
```

---

## 중요: 파일 이름에 공백이 있으면 따옴표로 감싸세요

파일 이름에 공백(빈칸)이 있으면 반드시 `"큰따옴표"`로 감싸야 합니다.

```
# 잘못된 예 (공백 때문에 quote> 오류 발생)
python3 transcribe.py /Users/jsw/Downloads/책 물리학 0421.m4a

# 올바른 예
python3 transcribe.py "/Users/jsw/Downloads/책 물리학 0421.m4a"
```

> 가장 쉬운 방법: 파일을 터미널 창에 **드래그앤드롭** 하면 경로가 자동으로 입력됩니다.
> (공백도 자동으로 처리됩니다)

---

## 기본 사용법

### 파일 하나 변환

```
python3 transcribe.py "파일경로"
```

결과는 **같은 폴더에 자동으로 .txt 파일로 저장**됩니다.

예시:
```
python3 transcribe.py "/Users/jsw/Downloads/회의녹음.mp3"
# → /Users/jsw/Downloads/회의녹음.txt 생성됨
```

---

### 폴더 전체 한 번에 변환 (새 기능)

폴더 경로를 주면 그 안의 **모든 오디오 파일을 자동으로 변환**합니다.
각 파일 옆에 같은 이름의 `.txt` 파일이 저장됩니다.

```
python3 transcribe.py "/Users/jsw/Downloads/녹음폴더"
```

예시 결과:
```
녹음폴더/
  ├── 강의1.m4a
  ├── 강의1.txt  ← 자동 생성
  ├── 강의2.m4a
  ├── 강의2.txt  ← 자동 생성
  └── 회의.mp3
  └── 회의.txt   ← 자동 생성
```

## 자주 쓰는 옵션들

### 언어를 직접 지정하고 싶을 때

자동 감지가 기본이지만, 명확하게 지정하면 더 정확합니다.

```
# 영어 파일
python3 transcribe.py 녹음.mp3 --language en

# 한국어 파일
python3 transcribe.py 녹음.mp3 --language ko
```

---

### 결과를 파일로 저장하고 싶을 때

화면에 출력되는 것과 동시에 텍스트 파일로도 저장됩니다.

```
python3 transcribe.py 녹음.mp3 --output 결과.txt
```

저장 위치는 현재 폴더(`~/transcribe`) 안에 `결과.txt`로 생깁니다.

---

### 몇 분에 무슨 말을 했는지 확인하고 싶을 때 (타임스탬프)

```
python3 transcribe.py 녹음.mp3 --timestamps
```

출력 예시:
```
[00:00.00 → 00:03.50]  안녕하세요, 오늘 회의를 시작하겠습니다.
[00:03.50 → 00:07.20]  첫 번째 안건은 예산 관련 사항입니다.
```

---

### 정확도를 높이고 싶을 때 (모델 변경)

모델이 클수록 정확하지만 처음 실행 시 다운로드 시간이 필요합니다.

```
python3 transcribe.py 녹음.mp3 --model large-v3
```

| 모델 이름 | 파일 크기 | 속도 | 정확도 |
|---|---|---|---|
| `tiny` | 75MB | ⚡⚡⚡⚡⚡ | ★★☆☆☆ |
| `base` | 145MB | ⚡⚡⚡⚡ | ★★★☆☆ 기본값 |
| `small` | 466MB | ⚡⚡⚡ | ★★★★☆ |
| `medium` | 1.5GB | ⚡⚡ | ★★★★☆ |
| `large-v3` | 3GB | ⚡ | ★★★★★ 최고 정확도 |

> 처음엔 `base` (기본값)로 써보고, 결과가 만족스럽지 않으면 `small` → `large-v3` 순으로 올려보세요.

## 옵션 여러 개 동시에 쓰기

옵션은 마음대로 조합할 수 있습니다.

```
python3 transcribe.py 녹음.mp3 --language ko --model small --output 결과.txt --timestamps
```

---

## 지원하는 파일 형식

아래 형식은 모두 바로 사용 가능합니다.

| 종류 | 확장자 |
|---|---|
| 오디오 | `.mp3` `.wav` `.m4a` `.flac` `.ogg` `.aac` |
| 영상 | `.mp4` `.mov` `.avi` `.mkv` |

---

## 처음 실행할 때 주의사항

**모델을 처음 쓸 때는 자동으로 다운로드됩니다** (인터넷 필요).
이후부터는 완전 오프라인으로 동작합니다.

| 모델 | 최초 다운로드 시간 (인터넷 속도에 따라 다름) |
|---|---|
| `tiny` / `base` | 1~2분 |
| `small` | 3~5분 |
| `large-v3` | 10~20분 |

## 자주 발생하는 오류

### "파일을 찾을 수 없습니다" 오류
```
오류: 파일을 찾을 수 없습니다 → 녹음.mp3
```
→ 파일 경로가 잘못됐습니다. 파일을 터미널 창에 **드래그앤드롭** 해서 경로를 자동 입력하세요.

---

### 패키지 없다는 오류
```
필요한 패키지가 없습니다.
```
→ 아래 명령어를 터미널에서 실행하세요:
```
pip3 install faster-whisper static-ffmpeg
```

```bash
python3 ~/transcribe/transcribe.py 파일경로 --language en --timestamps

# 최고 정확도
python3 ~/transcribe/transcribe.py 파일경로 --model large-v3 --output 결과.txt
```
