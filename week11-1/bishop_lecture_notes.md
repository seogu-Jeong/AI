## 1. 과학의 근본 질문

> "우리 세계가 수학으로 기술된다는 사실이 인류 최대의 과학적 발견이다."

- 단순한 방정식(Maxwell, Schrödinger 등)이 일상에서 경험하는 모든 현상을 기술
- 전자의 자기모멘트: 이론값과 실험값이 **13자리**까지 일치 → 방정식의 정밀도는 경이로운 수준
- **문제**: 방정식은 쓰기 쉽지만 풀기는 극히 어렵다 (Dirac, ~100년 전)

## 2. 과학적 발견 프로세스와 AI의 역할

```
[가설 수립] → [실험] → [관측/데이터] → [가설 수정]
                ↑
           [시뮬레이션] (1960s 디지털 컴퓨터 등장 이후)
                ↑
           [AI 에뮬레이터] (현재 — 세 번째 오라클)
```

AI가 영향을 미치는 영역:
- 가설 수립 (수백만 분자 후보 생성)
- 실험 데이터 분석 및 해석
- 자동화 웨트랩(wet lab) 구동
- 수백만 논문 처리 (인간 불가능)

## 3. No Free Lunch Theorem과 Inductive Bias

**핵심 원리**: 데이터만으로는 학습 불가. 반드시 **사전 지식(inductive bias)** 필요

| 분야 | 데이터 | Inductive Bias |
|------|--------|----------------|
| LLM (GPT 등) | 방대 (인터넷 스케일) | 가벼움 (attention 메커니즘) |
| 과학 | 희소하고 고비용 | 풍부 (물리 방정식 자체) |

과학에서의 Inductive Bias 예시:
- **슈뢰딩거 방정식** 자체
- **불변성(Invariance)**: 분자 회전 → 에너지 불변
- **등변성(Equivariance)**: 분자 회전 → 자기모멘트도 함께 회전
- **보존 법칙**: 에너지, 질량, 운동량, 전하 보존
- → 이것이 **기하학적 딥러닝(Geometric Deep Learning)** 의 기반

## 4. The Bitter Lesson (Rich Sutton, 2019)

> "더 많은 데이터가 항상 정교한 사전 지식을 이긴다."

- 수십 년간 prior knowledge를 네트워크에 내장 → 결국 더 많은 데이터+컴퓨팅이 능가
- 컴퓨터 속도의 지수적 증가 → 더 큰 모델, 더 많은 데이터가 승리
- **딜레마**: 방정식을 무시할 수 없지만, 데이터가 결국 이긴다 → 해결책: **딥러닝 에뮬레이터**

## 5. 딥러닝 에뮬레이터 (AI Emulator)

### 핵심 아이디어

```
시뮬레이터(느림, 정확) → [합성 데이터 생성] → 에뮬레이터 훈련 → [빠른 예측]
```

1. **데이터 생성 단계**: 기존 시뮬레이터(방정식 직접 풀기)로 대량의 훈련 데이터 생성 (1회성)
2. **훈련 단계**: 신경망을 해당 데이터로 훈련 → **에뮬레이터**
3. **활용 단계**: 에뮬레이터를 수천~수백만 번 반복 사용

### 에뮬레이터의 장점

| 항목 | 내용 |
|------|------|
| 데이터 라벨링 | 자동 (방정식 풀면 자동 생성) |
| 개인정보 이슈 | 없음 (물리 방정식 해) |
| 데이터 무한 생성 | 컴퓨팅만 있으면 언제든 추가 가능 |
| 속도 향상 | 시뮬레이터 대비 **1,000배 이상** (일반적으로 수천 배) |
| 활용 컴퓨팅 | 단일 GPU, CPU, 유휴 컴퓨팅 자원으로도 가능 |

## 6. 사례 1 — 날씨 예보 (NWP Emulator)

- 기존: 슈퍼컴퓨터로 대기 편미분방정식 6시간마다 수치 풀기
- 수십 년간 축적된 시뮬레이션 데이터 → **파운데이션 모델** 훈련
  - 다양한 시뮬레이터, 다양한 해상도, 다양한 시간 스케일
- **결과**: 영국 8일 날씨 예보를 **A100 GPU 1개로 1분** 내 완료
- 응용: 대기 오염물질(NOx) 흐름 예측 → 희소한 오염 센서 데이터 + 날씨 파운데이션 모델 파인튜닝 → 정확도 대폭 향상

## 7. 사례 2 — 분자/재료 설계 (Molecular Scale)

### 탐색 공간의 규모
- 약물-유사 소분자 수: **10⁶⁰개** (태양계 원자 수와 유사)
- 재료, 단백질: 더 거대한 조합 공간

### MataGen (확산 모델 기반 결정 구조 생성)
- 이미지 확산 모델과 동일 원리 → 결정(crystal) 구조 생성
- 노이즈에서 출발 → 원자 종류, 단위셀 기하, 원자 위치 점진적 denoising
- **조건부 생성**: 원하는 전자적/자기적/역학적 특성 입력 → 해당 특성의 결정 구조 생성
- 효과: 화학 공간에서 **원하는 특성을 가진 영역에 집중** → 스크리닝 효율 대폭 향상

## 8. 밀도 범함수 이론 (DFT)과 AI

### 슈뢰딩거 방정식의 어려움
- 파동함수 ψ: N개 전자의 3차원 좌표 공간 함수 → **지수적 계산 비용**
- 카페인(~100개 전자) → 300차원 공간 → 직접 풀기 불가능

### Walter Kohn의 DFT (노벨화학상 1998)
- 파동함수(지수 비용) 대신 **전자 밀도**(3차원)만으로 모든 성질 계산 가능
- **지수 → 3차 스케일링**으로 정확한 변환 (근사 아님)

```
파동함수 (지수적) → [DFT 변환] → 전자 밀도 (O(N³))
```

### Exchange-Correlation Functional 문제
- DFT의 Kohn-Sham 방정식 내 **교환-상관 범함수(XC functional)** 항: 정확한 해석적 형태 미지
- 지난 60년: ~800개의 수작업 근사 함수 개발 ("DFT Zoo")
  - 저비용 → 부정확 / 고정확 → 매우 비싼 스케일링
- **Kohn이 보인 것**: 단일 보편 XC functional이 존재함 (전체 화학 공간에 적용)

### SCALA (Microsoft AI for Science 프로젝트)
- **기계학습으로 보편 XC functional 학습**
- 혁신 1: 전자 밀도(포인트 클라우드) → 원자 중심 저차원 표현 → 메시지 패싱
- 혁신 2: 기존 공개 데이터의 **10배** 규모의 고정밀 양자화학 훈련 데이터 생성 (3년)
- 결과: 원자화 에너지에서 **화학적 정밀도(chemical accuracy)** 달성
- 현재 한계: 주족 원소 분자에만 적용 (전이 금속, 재료계 미적용)

## 9. 정확도 트릴레마 (Accuracy Trilemma)

```
         정확도 (Accuracy)
            /\
           /  \
          /    \
         /      \
        /________\
  속도 (Speed)  일반성 (Generality)
```

세 가지 모두를 동시에 최대화할 수 없다.  
AI 에뮬레이터 연구의 핵심 = **이 트릴레마에서 더 나은 균형점 찾기**

**화학적 정밀도(Chemical Accuracy)**: ~1 kcal/mol  
→ 계산 모델이 실험과 동등한 수준 → 실험실 실험 대폭 줄이고 계산 실험으로 대체 가능  
→ 달성하기 매우 어려운 높은 기준 (배의 무게 차이로 선장 무게 재기 비유)

## 10. 분자 동역학 (Molecular Dynamics)과 에뮬레이터

### 단백질 동역학의 중요성
```
DNA 서열 → RNA → 아미노산 서열 → 단백질 구조(3D) → 단백질 기능
```
- 구조(정적)는 AlphaFold로 거의 해결
- **미해결 문제**: 단백질의 동적 거동(열기/닫기, 도킹, 상호작용)

### 분자 동역학 계산의 이중 어려움
1. 각 스텝마다 슈뢰딩거 방정식 풀기 필요 (지수 비용)
2. **순차성의 저주**: 펨토초(10⁻¹⁵s) 타임스텝 × 밀리초 이벤트 = 10¹²~10¹⁵ 순차 스텝 필요
   - GPU는 병렬화로 빠르지만 클럭 속도는 수년간 불변 → 순차 연산 속도 개선 없음

### 에뮬레이터 기반 분자 동역학
- 원자 → **청크(chunk) 단위** 그룹화
- DFT로 청크 간 힘 계산 → 에뮬레이터 훈련
- 각 MD 스텝 = 에뮬레이터 호출 (피드포워드, 극히 빠름)
- **결과**: 최대 **10,000개 원자** 단백질 MD 시뮬레이션 가능

### Science 표지 논문
- 분자 동역학 + 실험 데이터(X선 회절) 파인튜닝
- 동역학 없이 **평형 분포에서 직접 샘플링** (희귀 이벤트 문제 우회)
- 단백질 1개 진공 상태 → 다음 목표: 단백질 간 상호작용, 수용액 환경
