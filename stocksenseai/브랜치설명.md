# Git 브랜치 설명

## 브랜치란?
같은 프로젝트를 **각자 독립된 공간**에서 작업할 수 있게 해주는 기능.
서로의 작업에 영향을 주지 않음.

---

## 브랜치 구조 (이 프로젝트 기준)

```
main (최종 완성본)
 └── dev (팀 전체 통합본)
      ├── seogu-Jeong (정석우 개인 작업공간)  ← 나
      ├── hwang (황○○ 개인 작업공간)
      └── 기타 팀원...
```

---

## dev vs seogu-Jeong 차이

| 구분 | dev | seogu-Jeong |
|------|-----|-------------|
| 용도 | 팀 전체가 합치는 공간 | 내 개인 작업 공간 |
| 누가 올림 | 모든 팀원 | 나만 |
| 언제 씀 | 내 작업 완료 후 합칠 때 | 평소 내 작업할 때 |

---

## 작업 흐름

1. **평소** → `seogu-Jeong` 브랜치에서 작업 & 푸시
2. **완성되면** → `dev` 브랜치에 합치기 (Pull Request)
3. **최종 완성** → `main`에 합치기

---

## 한 줄 요약

> `seogu-Jeong` = 내 작업실 / `dev` = 팀 공용 작업실 / `main` = 최종 제출본
