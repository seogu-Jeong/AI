# PRD — StockSenseAI
**Product Requirements Document**
버전: 3.0 | 작성일: 2026-05-31 | 작업자: 2명
레퍼런스: TradingView · 토스증권 · 나무증권 · Prospero.ai · TrendSpider · ifibought(그때샀다면)

---

## 1. 제품 개요

### 1.1 비전
AI 기반 한국 주식 차트 예측과 실제 거래 실행을 하나의 플랫폼에 통합한 웹 서비스.
토스증권 수준의 직관적 UX + TradingView 수준의 차트 분석 도구 + AI 예측 시나리오를 결합해,
초보 투자자부터 기술적 분석 중급자까지 모두 사용 가능한 플랫폼을 만든다.

### 1.2 핵심 차별점

| 경쟁 앱 | 강점 | StockSenseAI가 가져올 것 |
|---|---|---|
| TradingView | 차트·지표·Pine Script | 동급 차트 + AI 예측 오버레이 |
| 토스증권 | UX 73.2점, 진입 장벽 제거 | 동급 UX + 전문 분석 도구 |
| 나무증권 | 전문성·야간 모드·해외주식 | 동급 전문성 + AI 시그널 |
| Prospero.ai | AI 모멘텀 스코어 | 한국 주식 특화 AI 스코어 |
| TrendSpider | 150+ 캔들 패턴 자동 인식 | 45+ 패턴 + LSTM 예측 결합 |
| ifibought | 투자 회고 시뮬레이터 UX | 동급 깔끔한 라이트 UI + 시뮬레이터 탑재 |

### 1.3 제품 범위
- 대상 시장: 한국 주식 (코스피, 코스닥)
- 플랫폼: 웹 (PC) + 모바일 반응형 브라우저
- 거래 API: 한국투자증권 KIS Open API (무료, WebSocket 실시간 지원)
- 데이터: pykrx (무료 시세), KIS WebSocket (실시간 체결)

## 2. 사용자 정의

### 2.1 사용자 모드

| 모드 | 진입 조건 | 활성 기능 | 제한 |
|---|---|---|---|
| 데모 | 이메일 가입만 | AI 시그널 조회, 차트 분석, 모의투자 시뮬레이션, 백테스팅 | 실거래 불가, 공용 데모 키 사용 |
| 모의투자 | KIS 모의투자 API 키 등록 | 실제 주문 체결 (가상머니), 포트폴리오 추적 | 실거래 불가 |
| 실거래 | KIS 실거래 API 키 등록 | 전체 기능 이용 가능 | 리스크 설정 필수 |

### 2.2 핵심 페르소나

**페르소나 A — 주식 입문자 "김민준 (26세)"**
- 토스증권을 쓰다가 더 전문적인 분석이 하고 싶어졌다
- AI가 추천하는 종목을 보고, 왜 그런지 차트로 이해하고 싶다
- 목표: 데모 → 모의투자 → 실거래 단계적 전환

**페르소나 B — 기술적 분석 중급자 "이서연 (34세)"**
- RSI, MACD 직접 보고 매매한다. 나무증권 사용 중
- AI 예측 시그널이 본인 판단과 얼마나 일치하는지 검증하고 싶다
- 목표: 백테스팅으로 AI 전략 검증 후 실거래 적용

**페르소나 C — 포트폴리오 시연자 "개발자 박준영 (29세)"**
- 데모 모드로 취업·투자자에게 앱을 보여주고 싶다
- 실 API 키 없이도 모든 UI가 작동해야 한다

## 3. 기능 요구사항

### 3.1 온보딩 & 인증

**FR-01 회원가입**
- 이메일 + 비밀번호 가입
- 소셜 로그인: 카카오, 구글 (선택적)
- 가입 완료 시 이메일 인증 링크 발송
- 가입 완료 즉시 데모 모드로 입장, 튜토리얼 팝업 (스킵 가능)

**FR-02 로그인 & 세션**
- JWT 기반 (Access 30분, Refresh 7일)
- "로그인 상태 유지" 체크박스 (Refresh Token HttpOnly Cookie)
- 비밀번호 재설정 (이메일 링크, 30분 유효)
- 다중 기기 동시 접속 허용 (세션 독립)

**FR-03 KIS API 키 관리**
- 모의투자 키 / 실거래 키 각각 별도 등록
- 등록 시 자동 연결 테스트 (잔고 조회 API 호출)
- 키 AES-256 암호화 저장
- 키 교체 시 기존 세션 무효화 없음 (이미 캐시된 토큰 사용)

**FR-04 모드 전환**
- 헤더 상단 토글: 모의투자 ↔ 실거래
- 실거래 전환 시 2차 확인 모달 ("실제 돈이 사용됩니다")
- 데모 유저가 실거래 토글 시 KIS 키 등록 유도 배너

---

### 3.2 실시간 시세 & 대시보드

**FR-05 메인 대시보드**
- 코스피 / 코스닥 지수 실시간 (WebSocket, 5초 갱신)
- 지수 미니 차트 (당일 시가 기준 등락 라인)
- 개인 포트폴리오 요약 카드: 총 평가액, 당일 수익금, 수익률 (%)
- AI 추천 종목 섹션: BUY 시그널 강도 상위 5종목
- 관심 종목 목록: 종목명, 현재가, 등락률, AI 시그널 뱃지
- 시장 분위기 게이지: 전체 종목 BUY/HOLD/SELL 비율 도넛 차트
- 장 상태 배너: 장전/장중/장후/휴장 실시간 표시

**FR-06 종목 검색**
- 종목명 또는 종목코드 즉시 검색 (타이핑 즉시 결과)
- 최근 검색 종목 5개 저장
- 검색 결과: 종목명, 코드, 현재가, 등락률, AI 시그널 뱃지

**FR-07 관심 종목 (Watchlist)**
- 최대 50종목 등록
- 드래그로 순서 변경
- 종목별 가격 알림 설정 (목표가 도달 시 이메일)
- 관심 종목 그룹 생성 (최대 5그룹, 예: "반도체", "2차전지")

### 3.3 차트 & 기술적 분석

**FR-08 메인 차트 (TradingView Lightweight Charts 기반)**

차트 타입:
- 캔들스틱 (기본)
- 라인 차트
- 바 차트
- 영역 차트 (Area)
- 하이킨 아시 (Heikin Ashi) — 추세 파악에 유리

기간 탭:
- 1분 / 3분 / 5분 / 15분 / 30분 (장중 단기)
- 1시간 / 4시간 (중기)
- 일봉 / 주봉 / 월봉 (장기)

드로잉 도구:
- 추세선 (Trend Line)
- 수평선 / 수직선
- 피보나치 되돌림 (Fibonacci Retracement)
- 채널 (평행선)
- 텍스트 메모

**FR-09 기술적 지표 서브차트**

메인 차트 오버레이:
- 이동평균선: MA5, MA20, MA60, MA120 (색상 커스텀)
- 볼린저밴드 (MA20, 2σ)
- 거래량 막대 (색상: 상승=빨강, 하락=파랑)

서브 패널 (추가/제거 가능):
- RSI (14일, 과매수/과매도 기준선 30/70)
- MACD (12/26/9, 히스토그램 포함)
- 스토캐스틱 (14,3,3)
- OBV (On-Balance Volume) — 거래량 추세
- MFI (Money Flow Index) — 자금 흐름

**FR-10 캔들 패턴 자동 인식**
- 인식 대상 패턴 (45가지):
  - 반전 패턴: 망치형, 역망치형, 도지, 교수형, 유성형, 잉태형, 관통형, 먹구름형
  - 지속 패턴: 상승/하락 세 병사, 갭업/갭다운
  - 복합 패턴: 헤드앤숄더, 이중바닥/이중천장, 삼각수렴, 컵앤핸들
- 패턴 감지 시 차트 위에 아이콘 + 툴팁 표시
- 패턴 유형(반전/지속), 신뢰도(%), 과거 유사 패턴 성공률 표시

### 3.4 AI 차트 예측 *(핵심 기능)*

**FR-11 LSTM 가격 예측**
- 입력: 최근 60 거래일 OHLCV + 13개 기술적 지표 피처
- 출력: 다음 5 거래일 종가 예측
- 예측 신뢰도 (%) — 최근 20회 예측 vs 실제 방향 정확도
- 차트에 3가지 시나리오 오버레이 (점선 연장):
  - **강세 (Bullish)**: 상위 25% 예측 경로 (초록 점선)
  - **중립 (Base)**: LSTM 중앙값 (흰색 점선)
  - **약세 (Bearish)**: 하위 25% 예측 경로 (빨강 점선)
- 예측 갱신 주기: 매 장 종료 후 1회 (익일 장 전 준비)

**FR-12 AI 종합 시그널**
- 기술적 지표 점수 (40%) + LSTM 방향 점수 (60%) 가중 합산
- 시그널: **BUY / HOLD / SELL** + 점수 0~100
- 각 구성 요소별 점수 분해 표시 (기여도 막대)
- 시그널 변경 이력 타임라인 (최근 30일)

**FR-13 유사 패턴 히스토리 매칭 (TrendSpider 참고)**
- 현재 차트 형태와 과거 데이터에서 유사 패턴 Top 5 검색
- 각 유사 패턴 이후 5일/10일/20일 수익률 통계 표시
- "이 패턴 이후 평균 +3.2% (적중률 63%)" 형식

**FR-14 멀티 타임프레임 AI 분석**
- 일봉 / 주봉 / 월봉 3개 타임프레임 시그널 동시 표시
- 타임프레임 간 불일치 시 경고 배지 ("일봉 BUY, 주봉 SELL — 추세 충돌")

### 3.5 종목 스크리너

**FR-15 AI 스크리너**
- 필터 항목:
  - AI 시그널: BUY / HOLD / SELL
  - AI 시그널 점수 범위 (예: 70 이상만)
  - RSI 범위 (예: 30 이하 과매도 종목만)
  - 거래량 급증 (전일 대비 200% 이상)
  - 가격 범위
  - 시가총액 범위
  - 업종 필터 (반도체, 2차전지, 바이오 등)
- 결과 정렬: AI 점수순, 등락률순, 거래량순
- 스크리너 조건 저장 (최대 5개 프리셋)
- "오늘의 AI 추천 종목" 자동 프리셋 — AI 점수 75 이상 + BUY 시그널

### 3.6 거래 실행

**FR-16 주문 실행**
- 주문 유형: 시장가 / 지정가
- 주문 전 확인 모달:
  - 종목명, 수량, 예상 금액, 수수료 예상, 체결 후 잔고 미리보기
  - 현재 AI 시그널 표시 (주문 방향과 반대 시 경고)
- 모의투자/실거래 구분 색상: 파란 테두리(모의) / 빨간 테두리(실거래)
- 데모 유저: 실거래 주문 버튼 비활성화 + 안내 툴팁

**FR-17 주문 내역 & 관리**
- 당일 주문: 체결/미체결/취소 탭 구분
- 미체결 주문 즉시 취소
- 체결 내역: 종목, 수량, 체결가, 체결 시각, 수수료, 손익

**FR-18 호가창 (10단 호가)**
- 매수 10단 / 매도 10단 실시간 호가 표시
- 각 호가별 잔량 막대 시각화
- 호가 클릭 시 해당 가격 주문창에 자동 입력
- 체결량 실시간 스크롤 (하단 실시간 체결 내역)

---

### 3.7 포트폴리오

**FR-19 포트폴리오 현황**
- 보유 종목 목록:
  - 종목명, 보유수량, 평균매수가, 현재가, 평가손익, 수익률(%)
  - AI 현재 시그널 뱃지 (매도 타이밍 참고)
- 전체 요약: 총 매수금액, 총 평가금액, 총 손익, 총 수익률
- 종목 비중 파이차트
- 업종별 비중 파이차트

**FR-20 수익률 히스토리**
- 일별 포트폴리오 총 평가액 라인 차트
- 기간 선택: 1주 / 1달 / 3달 / 전체
- 성과 지표 (나무증권 수준):
  - 최대 낙폭 (MDD, Maximum Drawdown)
  - 샤프 비율 (Sharpe Ratio) — 위험 대비 수익
  - 승률 (%) — 매도 완료 종목 중 수익 비율
  - 평균 보유 기간

**FR-21 거래 이력**
- 전체 체결 내역 (날짜, 종목, 유형, 수량, 체결가, 손익)
- 기간 필터, 종목 필터
- CSV 다운로드

---

### 3.8 백테스팅

**FR-22 전략 백테스트 (TradingView Paper Trade 참고)**
- 백테스트 대상: AI 시그널 전략 또는 커스텀 지표 조합
- 설정 항목:
  - 백테스트 기간 (최대 2년)
  - 초기 투자금
  - 진입 조건: AI 점수 N 이상 시 BUY
  - 청산 조건: AI 점수 N 이하 시 SELL, 또는 목표 수익률/손절률 도달 시
  - 수수료율 설정
- 결과 출력:
  - 백테스트 기간 수익률 vs 코스피 지수 대비 초과수익
  - 총 거래 횟수, 승률, 최대 연속 손실
  - MDD, 샤프 비율, 연간 수익률 환산
  - 매매 시점이 표시된 차트 오버레이

---

### 3.9 리스크 관리

**FR-23 종목별 투자 한도**
- 종목당 최대 투자금액 또는 포트폴리오 비중(%) 설정
- 한도 초과 주문 시 경고 모달 후 차단
- 현재 비중 실시간 표시 (설정값 대비 %)

**FR-24 일일 손실 한도**
- 일일 최대 손실 금액 또는 비율 설정 (기본: -5%)
- 당일 실현손익 + 평가손익 합산 모니터링
- 한도 도달 시:
  - 추가 매수 자동 차단
  - 헤더에 빨간 경고 배너 상시 표시
  - 이메일 즉시 발송
  - 차단 해제: 사용자가 직접 설정 화면에서 수동 해제

**FR-25 손절가 / 목표가 자동 알림**
- 종목별 손절가 / 목표가 설정
- 도달 시 이메일 알림 + 앱 내 배너
- (실거래 only) 도달 시 자동 시장가 매도 옵션 (사용자 동의 필요)

### 4.1 성능

| 항목 | 목표값 | 측정 방법 |
|---|---|---|

| 시세 API 응답 (캐시 미스) | < 800ms | pykrx 직접 호출 |

| 차트 데이터 로딩 (일봉 1년) | < 1,000ms | |
| 웹소켓 체결 지연 | < 500ms | KIS WS 기준 |
| 모바일 초기 페이지 로드 | < 3,000ms | Lighthouse 기준 |

### 4.2 보안

| 항목 | 요구사항 |
|---|---|
| 통신 | HTTPS 필수 (HTTP → HTTPS 리다이렉트) |
| 인증 | JWT, Refresh Token HttpOnly Cookie |
| API 키 저장 | AES-256-GCM 암호화 |
| SQL 인젝션 | ORM 사용, Raw Query 금지 |
| XSS | React 기본 이스케이프, CSP 헤더 설정 |
| Rate Limiting | 로그인 5회/분, API 100회/분 per IP |
| 세션 탈취 | Refresh Token Rotation (사용 시 재발급) |

### 4.3 데이터

- 실거래 체결 데이터 영구 보존
- 모의투자 데이터 2년 보존
- 시세 캐시 데이터 24시간 후 자동 삭제

### 4.4 규정 및 법률

- KIS Open API 이용약관 준수 (1계정 WebSocket 41종목 제한)
- 개인정보 보호법: 이메일, 암호화된 API 키만 저장 (주민번호 등 미수집)
- 투자 관련 면책 문구 필수 표시 ("본 서비스는 투자 조언이 아닙니다")

## 6-B. 투자 시뮬레이터 기능 (ifibought 통합)

### FR-30 "그때 샀다면" 시뮬레이터

**개요:** 과거 특정 날짜에 종목을 매수했다면 현재 또는 지정 날짜 기준으로 얼마가 됐는지 계산.
ifibought의 핵심 기능을 StockSenseAI에 탭으로 통합.

**기능 상세:**
- 최대 4개 종목 동시 비교
- 투자 방식 선택:
  - **일시불**: 특정 날짜에 N원 일괄 투자
  - **적립식**: 매월 첫 거래일에 N원씩 정기 투자
- 매수일 / 매도일 자유 설정 (최근 7년치 데이터)
- 환율 적용: 국내 주식 KRW 기준 (현재 버전 v1 범위)

**결과 출력:**
- 종목별 수익금, 수익률(%)
- 비교 수익률 라인 차트 (x: 날짜, y: 수익률 %)
- 적립식 전용: 누적 투자금 vs 평가액 비교 차트 (교차점 = 원금 회복 시점)

**입력 검증 (ifibought 기준):**
- 미래 날짜 입력 → "오늘 이후의 날짜는 입력할 수 없습니다."
- 7년 이전 → 에러 + 가장 오래된 날짜 자동 이동
- 휴장일 → 다음 거래일로 자동 이동 + 안내
- 매도 < 매수 날짜 → 경고
- 투자 금액 0 또는 음수 → 차단
- 4개 초과 종목 → "최대 4개 종목까지 선택 가능합니다."

**결과 탭:**
- 시뮬레이션 실행마다 새 탭 생성 ("결과 1", "결과 2" ...)
- 결과 탭 ✕ 닫기 가능
- 탭 내 매도 날짜 수정 시 같은 탭에서 실시간 재계산

### FR-31 WatchlistPanel (하단 고정)

ifibought의 하단 투자 목록 패널과 동일한 패턴:
- 현재 시세 화면에서 종목 선택 → 하단 패널에 태그로 표시
- 각 태그에 ✕ 제거 버튼
- [일시불 투자] [적립식 투자] 버튼으로 시뮬레이터 모달 열기
- 최대 4종목 (초과 시 에러 토스트)

### FR-32 랜딩 페이지

비로그인 사용자에게 서비스를 소개하는 화면 (ifibought 구조 참고):
- 히어로 섹션: 서비스 슬로건 + CTA 버튼
- 기능 카드 4개: AI 예측 / 실거래 연동 / 투자 시뮬레이터 / 리스크 관리
- [Google로 시작하기] 버튼 (소셜 로그인)
- 30일 무료 체험 문구
