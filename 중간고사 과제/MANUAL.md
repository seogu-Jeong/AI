## 1. 앱 개요

StockSense AI는 4개의 딥러닝 모델(LSTM · CNN · Transformer · MLP)을 앙상블하여 미국 S&P 500 주요 종목의 **매수/보유/매도 신호**를 분석하고, 포트폴리오 최적화와 모의 투자까지 제공하는 데스크톱 애플리케이션입니다.

### 주요 기능 요약

| 기능 | 설명 |
|------|------|
| AI 스크리닝 | 앙상블 점수 기준 상위 종목 랭킹 |
| 종목 상세 분석 | 캔들차트 · 기술적 지표 · AI 신호 통합 보기 |
| 포트폴리오 최적화 | 투자 성향 기반 맞춤형 자산 배분 |
| 뉴스 감성 분석 | FinBERT 기반 뉴스 감성 점수화 |
| 관심 종목 | 알림 설정 및 포트폴리오 추적 |
| 전략 백테스팅 | 2019년~현재 AI 전략 vs S&P500 수익률 비교 |
| 모의 투자 | 실제 시세로 가상 매수/매도 연습 |

## 3. 스크리닝

AI가 분석한 S&P500 주요 종목을 **앙상블 점수 순으로** 랭킹합니다.

### 사용 방법

1. 앱 실행 시 자동으로 상위 30개 종목 목록이 표시됩니다
2. **필터 버튼** (All / Buy / Hold / Sell): MLP 신호 기준 필터링
3. **검색창**: 티커 심볼로 검색 (예: `NVDA`)
4. 종목 행 클릭 → **종목 상세** 페이지로 이동

### 표시 정보

| 컬럼 | 설명 |
|------|------|
| 순위 | 앙상블 점수 기준 순위 |
| 티커 | 종목 심볼 |
| AI 점수 | 0~100점, 높을수록 매수 신호 강함 |
| 신호 | MLP 모델의 Buy / Hold / Sell 판단 |
| LSTM | 5일 방향 예측 (Up / Down / Side) |
| CNN | 캔들 패턴 인식 결과 |
| 현재가 | 최근 종가 (USD) |
| 변동 | 전일 대비 등락률 |

### AI 점수 색상 기준

- 🟢 **80점 이상**: 강한 매수 신호
- 🟡 **60~79점**: 매수 고려
- ⚫ **40~59점**: 중립 / 보유
- 🟠 **20~39점**: 주의
- 🔴 **20점 미만**: 매도 신호

## 4. 종목 상세

선택한 종목의 **모든 AI 분석 결과**와 **기술적 지표**를 한 화면에서 확인합니다.

### 진입 방법
- 스크리닝 목록에서 종목 행 클릭
- 상단 검색창에 티커 입력 후 Enter

### 화면 구성

#### 상단 — 종목 기본 정보
- 티커명, 현재가, 전일 대비 등락률
- **앙상블 점수 게이지 바** (0~100)

#### AI 모델 카드 (4개)

| 카드 | 표시 내용 |
|------|-----------|
| **LSTM** | 점수 + 5일/20일/60일 방향 예측 |
| **CNN** | 점수 + 인식된 캔들 패턴명 |
| **Transformer** | 점수 + 어텐션 패턴 강도 |
| **MLP** | 점수 + Buy/Hold/Sell 확률 막대 |

#### 캔들차트 / 이동평균
- **90일** 캔들스틱 + 5일/20일 이동평균선
- **거래량** 패널
- **RSI(14)** 패널: 70 이상 과매수, 30 이하 과매도

#### 기술적 지표 패널 (우측)
각 지표명 옆 **?** 에 마우스를 올리면 설명이 표시됩니다.

| 지표 | 설명 |
|------|------|
| RSI(14) | 상대강도지수 (70↑ 과매수, 30↓ 과매도) |
| MACD | 이동평균 수렴·발산 지표 |
| BB%B | 볼린저 밴드 내 현재 위치 (1.0=상단) |
| Stoch%K | 스토캐스틱 오실레이터 |
| PER | 주가수익비율 |
| PBR | 주가순자산비율 |
| ROE | 자기자본이익률 |
| EPS Growth | 주당순이익 성장률 |
| Op Margin | 영업이익률 |

## 5. 포트폴리오 최적화

투자 성향을 설정하면 AI가 **맞춤형 종목 배분**을 추천합니다.

### 사용 방법

1. **투자 선호도 설정** (1~5점 입력)

| 항목 | 의미 |
|------|------|
| 수익 추구 (Return) | 5에 가까울수록 AI 고득점 공격적 종목 위주 |
| 안정성 (Stability) | 5에 가까울수록 저변동성 · 배당 종목 선호 |
| 배당 수익 (Dividend) | 5에 가까울수록 고배당 종목 우선 |
| 성장성 (Growth) | 5에 가까울수록 EPS 성장률 · 모멘텀 종목 선호 |
| 현금 보유 (Cash) | 5에 가까울수록 현금 비중 증가 (최대 40%) |

2. **운용 가능 자산** 입력 (USD)
3. **▶ AI 포트폴리오 생성** 버튼 클릭

### 결과 화면

- **총 투자 규모**: 입력한 금액
- **기대 수익률**: AI 점수 기반 1년 추정 수익률
- **위험도 (Max Drawdown)**: 추정 최대 낙폭
- **배분 막대 차트**: 종목별 비중을 수평 막대로 표시
- **종목 테이블**: 종목 · 비중 · 금액 · AI점수 · 매수 이유

### PDF/CSV 내보내기
- **PDF/CSV 레포트 저장** 버튼으로 포트폴리오 결과를 파일로 저장

## 6. 뉴스 / 감성 분석

관심 종목(또는 기본 8개 종목)의 최신 뉴스를 **FinBERT AI**로 감성 분석합니다.

### 화면 구성

- **포트폴리오 시장 감성 지수**: 전체 뉴스의 평균 감성 (EXTREME BULLISH ~ EXTREME BEARISH)
- **피드 동기화 버튼**: 최신 뉴스 재수집
- **뉴스 카드 목록** (감성 점수 강도순 정렬)

### 뉴스 카드 읽는 법

```
┌──────┬────────────────────────────────────────┐
│ NVDA │  NVDA posts record revenue in Q4...    │
│+0.72 │  Summary: NVIDIA reported...           │
│POSITIVE│ [ Yahoo Finance ]          2025-01-15│
└──────┴────────────────────────────────────────┘
```

| 요소 | 설명 |
|------|------|
| 티커 배지 (파란 박스) | 해당 뉴스의 관련 종목 |
| 감성 점수 (+0.72) | -1.0 ~ +1.0 (양수=긍정, 음수=부정) |
| POSITIVE/NEGATIVE/NEUTRAL | 감성 레이블 |
| 제목 | 뉴스 헤드라인 |
| 요약 | 기사 본문 요약 (최대 180자) |
| 출처 + 시간 | 뉴스 소스 및 발행 시간 |

### 기본 분석 종목
NVDA · AAPL · MSFT · META · AMZN · GOOGL · TSLA · JPM  
(관심 종목 등록 시 해당 종목으로 자동 교체)

## 8. 전략 백테스팅

AI 전략(상위 N종목 매월 리밸런싱)의 **과거 성과**를 S&P500과 비교합니다.

### 사용 방법

1. **시작일 / 종료일** 설정 (2019년 7월 이후 데이터 보유)
2. **상위 종목 수** 설정 (기본값 30, 범위 5~50)
3. **백테스트 실행** 버튼 클릭

### 결과 지표

| 지표 | 설명 |
|------|------|
| 전략 수익률 | 선택 기간 AI 전략 누적 수익률 |
| S&P500 | 같은 기간 벤치마크 수익률 |
| 최대 낙폭 (MDD) | 고점 대비 최대 하락폭 |
| 샤프 지수 | 위험 조정 수익률 (1.0↑ 양호) |

### 누적 수익률 차트
- **녹색 선**: AI 전략
- **남색 선**: S&P500
- X축: 날짜, Y축: 누적 배수 (1.0 = 원금)
- 스크롤하여 전체 내용 확인 가능

### 월별 수익률 상세 테이블
- 각 달의 전략 수익률, S&P500, **초과 수익률** 표시
- 초과 수익률 녹색 = AI 전략 우세, 빨간색 = S&P500 우세

> **참고**: 2019년 7월 이전 기간 선택 시 데이터 부족으로 데모 모드로 실행될 수 있습니다.

## 9. 모의 투자

**실제 시세**를 사용하되 가상 자금으로 매수/매도를 연습합니다.

### 초기 설정
- 상단 **초기 자금** 입력창에 원하는 금액 입력 (예: 50000)
- **계좌 초기화** 버튼으로 해당 금액으로 새 계좌 시작

### 매수 방법
1. **AI 추천 주문** 패널에서 티커 입력 (예: `AAPL`)
2. **현재가** 자동 조회 확인
3. **수량** 입력
4. **매수 (BUY)** 버튼 클릭

### 매도 방법
- **AI 추천 주문** 패널에서 티커 + 수량 입력 → **매도 (SELL)**
- **보유 종목 탭**에서 행 오른쪽 **매도** 버튼 클릭

### AI 추천 종목 퀵픽
- 오른쪽 하단 **AI 추천 종목** 버튼: AAPL · MSFT · NVDA · GOOGL · AMZN
- 클릭 시 자동으로 티커 입력창에 입력

### 보유 종목 탭

| 컬럼 | 설명 |
|------|------|
| 종목 | 티커 심볼 |
| 수량 | 보유 주수 |
| 평균단가 | 매수 평균 단가 |
| 현재가 | 실시간 조회 가격 |
| 평가금액 | 수량 × 현재가 |
| 손익 | 평가금액 − 취득원가 |
| 손익률 | 손익 / 취득원가 × 100 |

### 거래 내역 탭
- 모든 매수/매도 이력을 시간순으로 표시

> **자동 갱신**: 30초마다 현재가 및 손익 자동 업데이트

## 11. AI 모델 설명

StockSense AI는 4개의 딥러닝 모델을 **앙상블**하여 최종 점수를 산출합니다.

### LSTM (Long Short-Term Memory)

```
입력: 60일 OHLCV + 기술적 지표 시계열
출력: 5일 / 20일 / 60일 방향 예측 (Up / Down / Side)
특징: 시계열 패턴의 장기 의존성 학습
```

### CNN (Convolutional Neural Network)

```
입력: 캔들차트 이미지 (90일 × 픽셀)
출력: 캔들 패턴 인식 (Bullish Engulfing, Hammer, Doji 등)
특징: 시각적 차트 패턴을 이미지로 학습
```

### Transformer

```
입력: 다변량 재무 시계열 (가격 + 거래량 + 지표)
출력: 어텐션 가중치 기반 종합 점수
특징: Self-Attention으로 비선형 상관관계 포착
```

### MLP (Multi-Layer Perceptron)

```
입력: 펀더멘털 지표 (PER, PBR, ROE, EPS성장률 등) + AI 점수
출력: Buy / Hold / Sell 확률
특징: 재무 데이터 비선형 분류
```

### 앙상블 가중치

기본 가중치: `LSTM 35% · CNN 15% · Transformer 25% · MLP 25%`  
가중치는 데이터 업데이트 시 성과 기반으로 자동 조정됩니다.

## 12. 지표 용어 설명

| 지표 | 공식 / 설명 |
|------|-------------|
| **RSI** | 상대강도지수. 14일 기준. 70↑=과매수, 30↓=과매도 |
| **MACD** | 12일 EMA − 26일 EMA. 양수=상승 모멘텀 |
| **BB%B** | (현재가 − 하단밴드) / (상단 − 하단). 1.0=상단, 0=하단 |
| **Stoch%K** | 스토캐스틱. 80↑=과매수, 20↓=과매도 |
| **PER** | 주가 / 주당순이익. 낮을수록 저평가 가능성 |
| **PBR** | 주가 / 주당순자산. 1.0 미만=순자산 이하 거래 |
| **ROE** | 당기순이익 / 자기자본. 높을수록 자본 효율적 사용 |
| **EPS Growth** | 주당순이익 전년 대비 성장률 |
| **Op Margin** | 영업이익 / 매출액. 높을수록 수익성 우수 |
| **MDD** | Maximum Drawdown. 고점 대비 최대 낙폭 |
| **샤프 지수** | (수익률 − 무위험수익률) / 표준편차. 1.0↑=양호 |
