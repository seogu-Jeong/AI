## 슬라이드 5 — 차트 탭 : AI 분석 오버레이

**프롬프트:**
```
PPT "AI 분석 오버레이" 슬라이드를 작성해줘.

차트 위에 토글 버튼으로 ON/OFF 가능한 4가지 AI 기능:

[S/R] 지지·저항 레벨
→ K-means 클러스터링으로 과거 고점/저점 군집화
→ 수평 레벨 라인으로 표시

[추세선] 자동 추세선
→ scipy argrelextrema + 선형 회귀
→ R²≥0.5 신뢰도 필터 적용

[이상감지] Anomaly Detection
→ PyTorch Autoencoder 재구성 오차 기반
→ 비정상 급등락 구간 주황색 하이라이트

[예측선] LSTM 5일 예측
→ Bullish / Base / Bearish 3가지 시나리오
→ 종목별 개별 모델 학습

좌측에 4개 카드, 우측에 스크린샷 공간.
```
